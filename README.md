# GramJS — Typing Watcher (Node.js)

## Описание

Этот скрипт подписывается на "raw updates" через GramJS/TelegramClient и пытается отфильтровать события, связанные с индикатором набора текста (typing). Работает только если вы авторизованы как обычный пользователь (userbot) и являетесь участником того чата, где пользователь печатает.

**⚠️ ВАЖНО:** НЕЛЬЗЯ использовать для скрытного/незаконного наблюдения. Ответственность за законность использования — на вас.

## Особенности

- 📱 Мониторинг typing-событий в реальном времени
- 🤖 Интеграция с OpenAI ChatGPT для анализа сообщений
- 💬 Автоматические ответы на основе анализа чата
- 🔍 Глубокий анализ последних сообщений
- 🎭 Скрытая команда "ГУЛГИНГ" для естественных ответов

## Требования

- Node.js 18+
- npm

## Установка

1. Клонируйте репозиторий или скачайте файлы
2. Установите зависимости:
```bash
npm install
```

## Настройка

1. Создайте файл `.env` на основе `env.example.txt`:
```bash
cp env.example.txt .env
```

2. Заполните необходимые переменные окружения:

### Обязательные параметры:
- `TG_API_ID` — ваш Telegram API ID (получите на https://my.telegram.org)
- `TG_API_HASH` — ваш Telegram API Hash (получите на https://my.telegram.org)

### Опциональные параметры:
- `TG_SESSION` — строка сессии (StringSession). Если не указана — при первом запуске сохранится интерактивно
- `OPENAI_API_KEY` — ключ OpenAI API для анализа сообщений через ChatGPT
- `MESSAGE_LIMIT` — количество сообщений для анализа (по умолчанию 50)

## Запуск

```bash
node index.js username
```

Где `username` — имя пользователя Telegram для мониторинга (например: `node index.js geyzerfool`)

## Использование

### Во время работы скрипта:

#### Основные команды:
- **"анализ"** — анализ последних сообщений через ChatGPT (по умолчанию MESSAGE_LIMIT)
- **"анализ N"** — анализ последних N сообщений (например: "анализ 500")
- **"/question ваш вопрос number:500"** — ответ на вопрос на основе последних 500 сообщений

#### Скрытая команда "ГУЛГИНГ":
Напишите фразы типа:
- "даже не знаю"
- "хз"
- "не уверен"

Бот автоматически проанализирует последние 50 сообщений и отправит естественный ответ от вашего имени.

### Результаты:
- Результаты анализа и ответы отправляются в тот же чат, где была команда
- Скрипт отслеживает typing события в реальном времени

## Ограничения

- **Bot API НЕ даёт чужие "typing" события.** Для получения таких событий нужно авторизоваться как реальный пользователь (user account) через MTProto.
- **Если у пользователя скрыт last_seen/online** — это не влияет на typing-уведомления: они остаются ephemeral и видны участникам чата.
- Скрипт работает только в чатах, где вы являетесь участником.
